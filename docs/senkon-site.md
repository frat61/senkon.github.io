# senkonmuhendislik.com

Static site on GitHub Pages (branch `main`). No build step.

- `index.html` + `site.css`: the home page (design: `docs/superpowers/specs/2026-10-09-home-page-design.md`).
- `assets/senkon/`: logo (`logo.svg` the full vector, `logo-lockup.svg` the header lockup with the name beside the mammoth, `logo.png` for the share picture and icons), `logo-sketch.js` (draws the lockup inlined in the home-page header as a pen sketch, once per load), favicon, self-hosted fonts (`fonts/SOURCES.txt` records origin and hashes), the skyline band (`skyline.webp` picture, `skyline.json` building columns, `skyline-names.txt`) the Esenboğa project figure (`esenboga.webp`, `esenboga.json` with hand-placed cranes; off the page since 2026-10-14, kept for later), the steel hall in the hero (`hal.json`, the member lines and erection pieces made by `node tools/make-hall.js local/hall-ref/model.glb assets/senkon/hal.json` from the viewer's GLB of Fırat's model kept in gitignored `local/hall-ref/`; `hal.webp`, the still for visitors without JavaScript, by `python tools/make-hall-still.py assets/senkon/hal.json assets/senkon/hal.webp`; `hal.json` is format 2, members in metres with the camera and the default view's framing; `hal.js` projects them every frame and erects the hall element by element on a canvas in the hero media slot, above the headline on phones, then turns it slowly until the visitor touches it; dragging turns and tilts it, `touch-action: pan-y` keeps vertical swipes scrolling on phones, spec `docs/superpowers/specs/2026-10-14-hall-erection-design.md`); `skyline.js` animates every `figure[data-skyline]` (`data-speed` runs it faster, `data-stagger` spaces the starts of a picture cut into strips); `surec/01.webp … 06.webp` and `surec.js` are the six-picture story beside the steps on `deprem-performans/` (plays 5 s a frame, pauses when a step or Önceki/Sonraki is touched, resumes after 6 s; without JavaScript the pictures are a plain strip). Prompts for the pictures live in `local/surec-prompts.md`, the ChatGPT sources in `local/surec-src/`.
- `structkit/`: engineering calculators (own styles, own logo copy).
- `model/`: 3D model viewer and owner page (`docs/model/README.md`).
- `tools/`: `make-logo.py`, `make-logo-svg.py` (the vector logo and the header lockup from hand-traced vertices, inlined into `index.html` between the `logo-lockup` markers; letters from `logo-letters.json`, which `make-logo-letters.py` sets from the site's Work Sans and needs `pip install fonttools brotli`), `fetch-fonts.js`, `measure-skyline.py`, `make-og.py` (the 1200×630 share picture `assets/senkon/og.png`, from the skyline and the site's fonts; rerun after changing either), `make-model-sql.js`, `make-surec.py` (one of the six "Nasıl çalışıyoruz" story pictures: `python tools/make-surec.py local/surec-src/01.png 1` converts a ChatGPT drawing, `--placeholder 1` writes a numbered white card), `versions.js` (cache-busting tags, below).
- `tests/`: `node --test` (bare) runs everything.

GitHub Pages caches files for four hours, so each page links `site.css`, the fonts, the scripts and the drawings it uses with a `?v=` tag that is the hash of the file's content (a drawing's tag also covers its JSON). After changing any of them run `node tools/versions.js`; `tests/versions.test.js` fails until the tags match.

The skyline picture is composed from the ChatGPT drawing kept outside the repo (`local/skyline-chatgpt-v3.webp`): `python tools/compose-skyline.py <drawing> assets/senkon/skyline.webp --gap 60 --drop 1,7,10,11,15 --sky 70` (drops Flatiron, the İstanbul Airport tower, the Gherkin, SWFC and One WTC; `--insert i:file:height_px` can add a stand-alone drawing, e.g. the Esenboğa tower kept in `local/esenboga-ref/`). The Esenboğa figure: `python tools/compose-skyline.py --blank 1150x1500 assets/senkon/esenboga.webp --insert 0:local/esenboga-ref/esenboga-front.webp:1000 --margin 150 --sky 330`, then measure it and keep the `cranes` list in `esenboga.json`. After any change re-measure the building columns: `python tools/measure-skyline.py assets/senkon/skyline.webp assets/senkon/skyline.json assets/senkon/skyline-names.txt` (add `--split x` where two neighbours touch). Names in `skyline-names.txt` are in left-to-right order.
